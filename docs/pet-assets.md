# 桌宠素材（pet assets）

桌宠是常驻桌面的 Q 版初音未来小窗口（180×240 透明无边框，立绘显示宽度 140px），用动作与表情反映计时状态，头顶气泡实时显示当前活动与用时：

| 状态 | 素材文件 | 触发条件 |
| --- | --- | --- |
| 待机 | `pet-idle` | 默认状态（未计时，5 分钟内） |
| 计时中 | `pet-running` | 有正在进行的计时；同一立绘每 380ms 水平镜像交替（摆臂/迈腿必然换边、形象零漂移），配合垂直小弹跳形成慢跑动画 |
| 被拖拽 | `pet-drag` | 窗口正在被拖动（由 Go 侧 `pet:moving` 事件驱动） |
| 睡觉 | `pet-sleep` | 未计时超过 5 分钟自动打瞌睡 |
| 打招呼 | `pet-wave` | 单击桌宠，或计时开始的瞬间（约 2 秒反应） |
| 目标达成庆祝 | `pet-cheer` | 任一活动实时达到每日目标（Go 广播 `goal:achieved`），举手欢呼 5 秒并伴随彩纸雨 |

在此之上还有纯 CSS 的动态层：随机小动作（蹦跳/转身/跳舞/伸懒腰/小碎步，待机与计时中随机触发）和鼠标悬停时的雀跃反应，均无需额外素材。

## 文件与命名契约

素材放在 `frontend/src/assets/pet/`，按状态命名（扩展名不限）：

```text
pet-idle.png   pet-running.png   pet-cheer.png   pet-drag.png   pet-sleep.png   pet-wave.png
```

加载器 `frontend/src/lib/petAssets.ts` 通过 `import.meta.glob` 收集，同名时按
**webp > png** 优先级取用——把新的 AI 素材放进去即自动生效，无需改代码。

## 成品规格

- 透明底 PNG，**660×900** 画布（桌宠窗口内以 140px 宽度缩放显示，高分辨率源保证清晰）
- 人物底边对齐画布底边（脚本自动完成），头顶留少量空间
- 各图保持角色一致性：同一服装、发色、画风与光源；跑步动画由同一张立绘水平镜像
  交替实现（CSS `scaleX` 翻转），不需要生成第二帧
- 脚本会自动把 AI 漂移产生的饱和粉色杂色（多出现在黑色发带上）中和为黑灰，
  保证发饰与整套素材一致

## 用脚本再生成

生成脚本为 `tools/gen-pet-assets/gen-pet-assets.py`，调用 OpenAI 风格的
`images/generations` 接口，自动完成：生成 → 去背（优先模型透明底，否则白底
flood-fill 抠图）→ 裁剪 → 归一化到 660×900 底对齐 → 量化压缩。

```bash
export PET_IMG_API_KEY=你的密钥            # 只从环境变量读取，不会写入任何文件

python tools/gen-pet-assets/gen-pet-assets.py \
  --endpoint https://www.cafecode.work/v1/images/generations \
  --model gpt-image-2 --size 1024x1536 \
  --out frontend/src/assets/pet

# 只重新生成某几个状态：
#   ... --only idle,wave
# 只处理本地已有原图（跳过调用 API）：
#   ... --skip-generate
```

说明：

- 原图缓存在系统临时目录（`--raw-dir` 可改），处理结果直接写入 `--out`。
- 每个状态旁会生成 `*.debug.jpg`（灰底合成图），用于肉眼检查去背边缘，不会
  被 Vite 打包（不在 assets 目录留存）。
- 提示词在脚本的 `CHARACTER` 与 `STATES` 常量中维护：`CHARACTER` 是五张图共用
  的角色描述块（保证一致性），`STATES` 是各状态姿势描述。想换形象（比如改成
  其他角色或画风）只需改这两处。

## 用即梦等工具手工生成

若要在外部工具（即梦 / niji·journey / SD 等）生成，按以下提示词模板出图后抠
透明底，再按「成品规格」处理并放入 `frontend/src/assets/pet/` 覆盖同名文件。

**通用角色块（每张都带）：**

> Q版贴纸风初音未来插画，二头身Q版比例，超大头小身体，葱青色双马尾配黑色发带，
> 大大的青色眼睛，灰色无袖衬衫配青色领带，灰色百褶裙，黑色分离式袖套，黑色过膝
> 靴配青色滚边，粗描边，平涂赛璐璐上色，色彩鲜艳，全身居中带留白，纯白背景，
> 无阴影无地面，无文字无水印无边框，无场景

**各状态姿势词：**

- 待机：自然站立，双臂垂在身侧，抿嘴微笑，正视前方，正面视角
- 计时中：朝观者方向欢快奔跑，迈步中，一臂前摆一臂后摆，张嘴兴奋笑容，发带飘动
- 被拖拽：被提到半空，双臂高举过头，双腿悬垂，瞪大眼睛小张嘴，惊讶但可爱
- 睡觉：抱膝坐在地上，闭眼安睡，脸颊贴在膝盖上，双马尾垂在身侧
- 打招呼：站立，单手高举挥手问好，闭眼大笑，另一臂自然下垂

**负面词：** 背景景物、地面阴影、文字、水印、边框、多余肢体、写实风格
